# Barème de confiance et critères de validation

- A : étude instrumentée (uniquement la portée qu'elle mesure).
- B : fédération, nomenclature ou recommandation technique.
- C : entraîneur professionnel documenté sans preuve instrumentée.
- D : observation photographique/vidéo uniquement.

Une technique n'obtient PAS une validation biomécanique parce qu'une étude concerne sa famille.
