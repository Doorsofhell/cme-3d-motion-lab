# Atlas GitHub international
Date : 24 octobre 2026. Ce catalogue distingue index, réutilisation autorisée et donnée non autorisée.

## Ressources prioritaires
- BJJ Commons : 12 chaînes conditionnelles et dix fiches de positions, CC BY-SA 4.0. Liens seulement dans la base.
- BoxingVI : six classes de poings, 6915 clips déclarés ; licence des vidéos non établie.
- Thai-Boxing : 15 classes Mae Mai, 900 clips annoncés, publication pour recherche. Quinze noms ajoutés au référentiel.
- DeepMimic : 65 trames punch, 47 kick, 78 spin-kick, fichiers texte. Code MIT; provenance des mouvements non validée.
- Posetrak : capture vidéo multi-caméras, Apache 2.0, pas de corpus prêt.
- MimicKit et ProtoMotions : moteurs d'imitation pour apprentissage hors ligne, code Apache 2.0.
- PHC : contrôle humain et retargeting, BSD 3-Clause Clear pour le code.
- KungfuBot : contrôle dynamique, CC BY-NC, référence seulement.
- La Forge Animation Dataset : transitions locomotion CC BY-NC-ND, documentation uniquement.
- Judo-Throw-Predictor : extraction de poses de 2500 clips déclarés, droits des enregistrements sportifs non clarifiés.
- Judo Stats : statistiques et non cinématique.
- Free Mocap Library : index d'assets, licence CC0 revendiquée au niveau dépôt, statut des assets individuels à confirmer.
- GhostTrial : retargeting vers robot, pas un modèle biomécanique humain directement utilisable.

## Décision
L'intégration actuelle ne concerne que **métadonnées, noms de classes et liens**. Pour produire des animations réellement naturelles, il faudra des références 3D sous licence claire, du retargeting contrôlé et des comparaisons visualisées.
