# CME-3D 0.7.42 — sources et limites des étalons CC0

Deux silhouettes anatomiques réelles MakeHuman/MPFB dérivées CC0, riggées en A-pose avec 163 os annoncés par Innerscene. Sources :
- Homme : https://www.innerscene.com/tools/library/3d-parts/male-base-mesh-3d-person-rigged-a-pose-380e6d89
- Femme : https://www.innerscene.com/tools/library/3d-parts/female-base-mesh-3d-person-rigged-a-pose-dba97ed5

Licence publique annoncée sur chaque page : CC0-1.0 ; modèle MakeHuman/MPFB adapté par Innerscene. Les GLB sont téléchargés, contrôlés en structure (glTF, SKIN, JOINTS_0, WEIGHTS_0), puis inclus seulement dans les artefacts compilés. Hashes SHA256 et provenance produits dans le manifeste distribué.

**Limites** : forme 3D réellement organique mais pas sculpture conçue exclusivement selon les photos fournies. Le rig 163 os n'est pas le CoachRig canonique. Il reste en lecture seule, sans animation ni slider trompeur. Retargeting, morphs anatomiques avancés, inspection visuelle 360°, validation Android et alignement artistique sont à conduire avant de remplacer les coachs de combat. Shadow Studio inchangé.
